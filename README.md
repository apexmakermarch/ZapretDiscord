> [!WARNING]
>
> ### Реакция антивирусов
> Антивирус может среагировать на WinDivert.  
> Это средство перехвата и фильтрации трафика, необходимое для работы zapret.
> WinDivert способен применяться как безопасными, так и вредоносными программами, однако сам вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Ряд антивирусов считает файлы WinDivert потенциально опасными или относящимися к хакерским инструментам. В результате файл удаляется и помещается в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите проверку PUA — потенциально нежелательных приложений. Например, Kaspersky предлагает настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Исключение предпочтительно при грамотной настройке; если вы не уверены в своих действиях, лучше отключить обнаружение PUA.

## ⚙️ Установка и запуск

1. Настройте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и выберите собственного поставщика, то есть не вариант "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
    * Пользователям роутеров Keenetic нужно включить параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно.

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/apexmakermarch/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Распакуйте файлы в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий скрипт:
    * Чтобы найти рабочую стратегию, откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
    * Для автоматического запуска перейдите в **`service.bat`** -> `Install Service` и укажите подходящую стратегию.

## ℹ️ Что делают основные файлы

- [**`general.bat ...`**](./general.bat) запускает выбранную стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому пробуйте варианты **ALT**, **FAKE** и другие, пока не найдёте подходящий для себя.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через `services.msc`.</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода, автозапущенной стратегии и WinDivert.
  - **`Game Filter`** — включить или отключить обход для игр и других служб, работающих с UDP и TCP-портами выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Текущее состояние — включено или выключено — показано в скобках.
  - **`IPSet Filter`** — изменить режим обработки сервисов из `ipset-all.txt`.  
  Это пригодится при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках отображается один из режимов:
    - `none` — ни один IP не проверяется;
    - `loaded` — проверяется принадлежность IP списку;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений.
  - **`Replace active fakes`** — заменить используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и соединения с голосовым чатом Discord.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — проверить распространённые причины неработоспособности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если приложение внезапно перестало подключаться.
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`;
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно заметить на панели задач. Если этого не произошло, обратитесь к [#522](https://github.com/apexmakermarch/zapret-discord-youtube/issues/522).

### Рабочей стратегии нет

1. Откройте командную строку от имени администратора.
2. Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не открывается Telegram в браузере

Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:

- скопируйте весь текст из открытого блокнота;
- в новой папке найдите `hosts` и откройте его текстовым редактором от имени администратора;
- вставьте скопированное в конец `hosts` или замените ранее добавленный аналогичный блок;
- сохраните файл и проверьте подключение. Если результата нет, убедитесь, что файл действительно сохранился.

#### Результат не гарантируется. Если способ не помог, установите [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/apexmakermarch/tg-ws-proxy) либо любой публичный прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> После обнаружения определённая стратегия может утратить работоспособность, даже если раньше некоторое время всё было нормально.
> В репозитории есть много вариантов обхода. Если готовые варианты не подходят, создайте собственную стратегию на основе одной из них и измените её параметры.
> Описание параметров доступно [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

Проверьте следующее:

- нет ли ошибок в `service.bat` -> `Run Diagnostics`;
- присутствует ли адрес нужного ресурса в списках доменов или IP;
- работают ли другие варианты, например **`ALT`** или **`FAKE`**;
- помогает ли полная переустановка по инструкции ниже;
- ознакомьтесь с [#765](https://github.com/apexmakermarch/zapret-discord-youtube/issues/765).

### Как выполнить полную переустановку или обновление

- Сохраните ресурсы и данные, которые добавляли вручную.
- Перезапустите устройство.
- Откройте `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце ответьте `Y`.
- Удалите старую папку zapret.
- Загрузите последнюю версию со [страницы релизов](https://github.com/apexmakermarch/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть пункт разблокировки, установите его, нажмите "Применить" и "ОК".
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы.
- Запускайте разные `general`-скрипты и проверяйте ресурсы. Если доступ не появился, закройте программу через значок замка на панели задач и выберите другую стратегию.
- Найдя рабочую стратегию, добавьте её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

Инструкция доступна по адресу: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался в службах

1. В командной строке Windows, открытой через Win+R -> `cmd`, найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не загружается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если выбранная раньше перестала работать.
- Дополнительная информация есть в [#251](https://github.com/apexmakermarch/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, помогла ли очистка в приложении Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/apexmakermarch/zapret-discord-youtube/discussions/252).

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Установите [tg-ws-proxy](https://github.com/apexmakermarch/tg-ws-proxy).
- Либо воспользуйтесь бесплатным MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальную последовательность:

- через `service.bat` обновите ipset и активируйте `Game Filter`;
- если это не решило проблему, дополнительно включите `ipset any`.

У режима `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Не оставляйте его включённым постоянно. Определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/apexmakermarch/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

Опишите проблему [в issues](https://github.com/apexmakermarch/zapret-discord-youtube/issues).

## 🗒️ Как добавить адреса других ресурсов

Списки можно расширить вручную:

- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть уже указана в `ipset-all.txt`, но отдельный домен фильтровать не требуется;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить.

Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.

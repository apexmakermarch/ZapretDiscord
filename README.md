>
> Часть антивирусов относит файлы WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и попадает в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Поместите папку с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы хорошо понимаете настройку исключений, предпочтительно добавить исключение; если нет — рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика DNS, отличный от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (поставщик Cloudflare может оказаться заблокирован)
    * Windows 11 умеет включать Secure DNS непосредственно в настройках системы — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый вариант
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут быть нарушены

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/apexmakermarch/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите необходимый файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автоматический запуск, выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — сменить режим обхода для игр и прочих сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После смены режима стратегию необходимо перезапустить.**  
  Текущий статус (включено/выключено) отображается в скобках.
  - **`IPSet Filter`** — изменить режим обхода ресурсов из `ipset-all.txt`.  
  Этот пункт полезен при проверке ресурса, который без zapret работает, а с ним — нет  
  В скобках показывается состояние:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или выключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — получить актуальную версию `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении его работы
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться winws.exe, отвечающий за обход.  
Если его нет, обратитесь к [#522](https://github.com/apexmakermarch/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезапустите компьютер

### Не работает телеграм (веб версия)
В **`service.bat`** выберите **`Update hosts file`**. Если используемый hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте всё содержимое открывшегося блокнота
  - Откройте текстовым редактором от имени администратора файл `hosts` в созданной папке
  - Вставьте скопированный текст в конец `hosts` или замените прежнюю аналогичную запись
  - Сохраните файл и проверьте подключение ещё раз. Если результат не изменился, убедитесь, что `hosts` действительно сохранился.

#### Результат не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/apexmakermarch/tg-ws-proxy) либо любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Работа стратегий может прекращаться со временем.**
> Стратегия иногда функционирует некоторое время, а затем перестаёт работать после того, как её обнаруживают.
> Здесь собрано много вариантов обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них, изменив её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и убедитесь, что там нет ошибок

- Проверьте, внесён ли адрес ресурса в доменные или IP-списки

- Переключитесь на другие стратегии (**`ALT`**/**`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/apexmakermarch/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце ответьте Y
- Удалите каталог zapret
- Загрузите свежую версию со [страницы релизов](https://github.com/apexmakermarch/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть "Разблокировать", включите этот пункт, нажмите "Применить" и затем "ОК"
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте ресурсы. Если интернет не работает, закройте программу (в панели задач отображается значок замка) и выберите другую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на неожиданные ресурсы.

### Античит ругается на WinDivert

- Инструкция доступна здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы через командную строку Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив полученное имя в обе команды:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/apexmakermarch/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord
- Снова проверьте приложение Discord: помогла ли очистка?
- Проверьте Discord через браузер: https://discord.com/app. Если сайт открывается, можно пользоваться браузерной версией.
- Если Discord не открывается и в браузере, повторите проверку всех стратегий. YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/apexmakermarch/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/apexmakermarch/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если это не сработало, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` способен нарушить открытие множества сайтов. Не оставляйте его включённым постоянно: выясните IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/apexmakermarch/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

- Опишите её [здесь](https://github.com/apexmakermarch/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Новые адреса можно добавить в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены будут учитываться автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен этой сети фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
